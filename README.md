## 🎯 Objectif

Créer des **Bubble Charts** et des **Radar Charts** pour explorer et visualiser vos données avec style !

---

## 🚀 Instructions

### 1️⃣ Configuration

1. Clonez ce repository :
   ```bash
   git clone https://github.com/votre-utilisateur/bubble-radar-charts-tutorial.git
   ```


### 2️⃣ Utilisation

#### 📌 Bubble Chart

- Ouvrez le fichier `examples/bubble_chart.py`. 
- Exécutez le script pour générer un graphique des bulles interactif. 🎈
  ```bash
  python examples/bubble_chart.py
  ```
- Résultat attendu : un graphique mettant en évidence les relations entre les dimensions de vos données. ✨

#### 📌 Radar Chart

- Ouvrez le fichier `examples/radar_chart.py`.
- Exécutez le script pour générer un graphique radar fascinant. 🎯
  ```bash
  python examples/radar_chart.py
  ```
- Résultat attendu : une visualisation claire des variations sur plusieurs dimensions. 🌟
